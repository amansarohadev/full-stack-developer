# Full Stack Developer Portfolio / Projects

Welcome to the `full-stack-developer` repository! 

This repository contains various projects, exercises, and HTML examples related to full-stack web development.

## 📂 Projects

Here are the interactive applications and larger projects available in the `/projects` directory:

- **Birthday card** - A digital birthday card or greeting application.
- **Blackjack Game** - A functional browser-based Blackjack game.
- **business card** - A digital business card web page.
- **Chrome Extension** - A custom extension built for Google Chrome.
- **cricket scoreboard app** - An app to track scores for a cricket match.
- **following button** - A UI component mimicking a social media "Follow" button.
- **google search** - A clone or recreation of the Google Search homepage.
- **passenger counter app** - A simple tally counter app for counting passengers.
- **passwordGenerate** - A tool to generate secure, randomized passwords.
- **Space Exploration Site** - A themed website dedicated to space exploration.
- **Unit Converter** - An application to convert values between different units.

## Setup & Running

Depending on the specific project, setup instructions may vary. For simple HTML/JS projects, you can usually just open the `index.html` file in your browser or run a local server (like Live Server in VS Code) from the project's folder.
